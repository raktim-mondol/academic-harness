# Vendored CSL styles

`citation-format.js` registers these CSL styles with citation-js in addition to
the APA, Vancouver, and Harvard1 styles that ship with
`@citation-js/plugin-csl`.

| File | Style |
|---|---|
| `ieee.csl` | IEEE Reference Guide |
| `chicago-author-date.csl` | Chicago Manual of Style, author-date |
| `modern-language-association.csl` | MLA |

Source: <https://github.com/citation-style-language/styles> (retrieved from
`master` on 2026-10-23). The files are unmodified.
